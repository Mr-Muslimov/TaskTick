# TaskTick — задачи, календарь и привычки

Клон TickTick на чистом HTML/CSS/JS: списки задач, четыре вида календаря, Kanban-доска,
привычки со стриками, фокус-таймер и статистика. Без сборки, без зависимостей, без сервера —
данные хранятся в `localStorage` устройства. Полностью адаптивно, работает офлайн,
устанавливается как приложение (PWA) и упаковывается в APK.

![TaskTick](icons/icon-512.png)

## Возможности

**Задачи**
- списки и теги с цветами, приоритеты, даты, время, повторы, подзадачи, заметки;
- быстрое добавление с разбором текста: «Купить молоко завтра 9:00 #дом ~Покупки !!!»;
- сортировки (умная, по дате, приоритету, названию, вручную), поиск, отмена удаления;
- цвет задачи для подсветки в списке, календаре и на доске;
- порционная отрисовка — 10 000 задач без фризов.

**Календарь** — день / 3 дня / неделя / месяц, сетка по часам, «весь день»,
создание задачи тапом по слоту нужного времени, перетаскивание задач по датам.

**Доска** — колонки «К выполнению / В работе / Готово», перетаскивание карточек.

**Привычки** — недельная сетка с навигацией по прошлым неделям, текущая серия 🔥,
рекорд 🏆, всего отметок и прогресс недели.

**Фокус** — помодоро 25/5/15 с кольцевым прогрессом и выбором задачи.

**Оформление** — светлая и тёмная темы, адаптив 320–1920 px, тач-таргеты ≥ 40 px.

**Управление** — Drag & Drop мышью и долгим нажатием на телефоне; горячие клавиши
`1`–`6` (виды), `N` (новая задача), `/` (поиск), `B` (доска), `V` (выделение), `Esc`.

## Структура

```
index.html            разметка
styles.css            темы, адаптив, компоненты
manifest.webmanifest  PWA-манифест (standalone, иконки, shortcuts)
icons/                иконки 192/512, maskable, apple-touch, svg
js/icons.js           SVG-иконки
js/store.js           данные, localStorage, миграция схемы
js/app.js             логика и рендер
```

## Запуск

Просто откройте `index.html` двойным кликом — всё работает через `file://`.

Для установки как приложение и для корректной работы манифеста нужен HTTP:

```bash
python -m http.server 8080
# затем http://localhost:8080
```

## Сборка APK

Приложение готово к упаковке через [Capacitor](https://capacitorjs.com/):

```bash
npm init -y
npm i -D @capacitor/cli
npm i @capacitor/core @capacitor/android
npx cap init TaskTick com.example.tasktick --web-dir=.
npx cap add android
npx cap sync
npx cap open android     # сборка APK в Android Studio
```

Либо через [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) для TWA,
если сайт опубликован по HTTPS (GitHub Pages подходит).

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы:

```bash
git init
git add .
git commit -m "TaskTick: задачи, календарь, привычки"
git branch -M main
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

2. Settings → Pages → Source: **GitHub Actions** (или ветка `main`, папка `/root`).
   Готовый workflow лежит в `.github/workflows/pages.yml`.
3. Приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

## Данные и приватность

Всё хранится локально в браузере (`localStorage`, ключ `tasktick.v1`), ничего не отправляется
в сеть. Резервная копия — экспорт ключа `tasktick.v1` из DevTools → Application → Local Storage.
